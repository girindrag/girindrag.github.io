#  Girindra Mohan — macOS Portfolio Website

A personal website and portfolio for **Girindra Mohan** (Cloud / IoT Engineer & Team Lead) designed with an authentic, responsive macOS Sonoma/Sequoia desktop UI.

Built with **React 18, Vite, and Tailwind CSS**, featuring draggable/resizable windows, top Menu Bar, Control Center, Spotlight Search (`Cmd+K`), interactive zsh Terminal, Finder project explorer, and floating bottom Dock.

Hosted **100% Free** via **GitHub Pages** with automated CI/CD deployment via GitHub Actions.

---

## 💻 Features

- ** macOS Menu Bar**: Apple dropdown menu, active window title, battery & Wi-Fi indicator, Dark/Light mode toggle, and live digital clock.
- **Spotlight Search (`⌘K`)**: Instant search across projects, technical competencies, career history, and contact methods.
- **Interactive Terminal (zsh)**: Built-in terminal simulator with commands like `help`, `bio`, `skills`, `projects`, `exp`, `contact`, and `clear`.
- **Finder Projects Explorer**: Filterable multi-view showcase (Grid / List) for enterprise infrastructure, IoT fleets, and DevOps automation.
- **System Architecture & Skills**: Detailed visual gauges highlighting Docker, Kubernetes, Ansible, Azure IoT, Debian 11, and RHEL.
- **Notes Career Timeline**: Structured log of production roles at Harman Connected Services, DXC Technology (SBI-ITFO), and Genex Corporate Services.
- **Resume Downloader**: Instant 1-click access to download Girindra Mohan's complete verified CV in PDF format.
- **macOS Floating Dock**: Magnified hover physics with running-indicator dots.
- **Control Center**: Dynamic toggles for Wi-Fi, Bluetooth, Dark Mode, and display metrics.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/girindrag/girindrag.github.io.git
cd girindrag.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to see the macOS desktop interface.

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this repository to GitHub under:
   ```
   https://github.com/girindrag/girindrag.github.io
   ```
2. In your GitHub repository settings:
   - Navigate to **Settings** → **Pages**
   - Under **Build and deployment** → **Source**, select **GitHub Actions**
3. On every push to `main`, GitHub Actions will build and deploy the site live to:
   ```
   https://girindrag.github.io/
   ```
